# Omabar

Touch Bar layouts for [Omarchy](https://omarchy.org) on Intel T2 MacBook Pros.

Omabar puts 17 ready-made layouts on your Touch Bar, shows each one as a to-scale preview in a bar panel, and switches between them with one click, or automatically as you move between apps. It's built on [tiny-dfr](https://github.com/AsahiLinux/tiny-dfr).

- **17 layouts:** Duotone, Duotone Weather, Quiet, Keycaps, Workspaces, Capture, Windows, Desk Clock, Studio, Meeting, Dev, Themes, Quick Settings, Clipboard, Presenter, Browser and Numpad.
- **Live preview:** every layout drawn at your Touch Bar's real size, with its Fn row.
- **Follow the focused app:** a terminal gets Dev, the browser gets Browser, Spotify gets Studio. Unmatched apps and empty desktops go back to the layout you picked yourself.
- **Weather:** a condition icon and the temperature next to the clock, refreshed every 15 minutes. Tap it for the forecast.
- **Colours:** Omabar's own green and ice look, or **match your Omarchy theme**. Theme colours update when you switch themes and are kept readable on the Touch Bar's black, light themes included.
- **No password prompts** after a one-time setup, and **no blinking**: tiny-dfr reloads the layout in place.
- **Survives sleep:** Intel T2 Macs drop the Touch Bar on resume, and Omabar brings it back.

## Requirements

- An Intel T2 MacBook Pro with a Touch Bar (MacBookPro15,x or 16,x) running Omarchy on the `linux-t2` kernel.
- The `arch-mact2` package repository, which t2linux installs set up. Omabar's setup installs `tiny-dfr` from it.

## Dependencies

| What | Why | Where it comes from |
|---|---|---|
| `tiny-dfr` | Draws the Touch Bar | `arch-mact2` repo. Omabar's setup installs it. |
| `linux-t2` kernel with `appletbdrm` | The Touch Bar display driver | t2linux / Omarchy on T2 Macs |
| Python 3.11+ | Omabar's backend (`bin/omabar`) | Omarchy base system |
| polkit (`pkexec`) | Runs Omabar's root helper. A rule installed by setup lets only your user run only that helper, without a password. | Omarchy base system |
| Hyprland (`hyprctl`), Omarchy shell (Quickshell) | Binds for buttons that run commands; the panel | Omarchy |
| `curl` | Weather (Open-Meteo; location from Omarchy's weather settings, or an IP lookup via wttr.in) | Omarchy base system |
| fontconfig, JetBrains Mono Nerd Font | Text and glyphs on the Touch Bar | Omarchy defaults |

Some buttons launch optional apps and only work when they're installed: `hyprpicker` (Capture), `lazygit` and `lazydocker` (Dev), and Spotify (Studio).

Omabar uses root once, to set things up (see below), and afterwards only through its helper. The helper accepts exactly two things: a tiny-dfr config generated by Omabar, and Omabar's own icons (plain SVGs). Setup also adds a udev rule and a systemd service that restart tiny-dfr after sleep, and it writes a marked block of binds into `~/.config/hypr/bindings.lua`.

## Install

```bash
omarchy plugin add https://github.com/jonathanintheclouds/omabar.git --enable
```

Click the keyboard icon (󰌌) that appears in the bar, then press **Set up** and enter your password once. Setup will:

1. install and enable tiny-dfr,
2. install a small root helper and a polkit rule so switching needs no password,
3. install the sleep/resume fix,
4. switch the Touch Bar from Apple's keyboard mode to a display. If it can't do that without a reboot, it tells you.

Then pick a layout and press **Activate**.

Setting up from a terminal instead works too:
```bash
sudo ~/.config/omarchy/plugins/io.github.jonathanintheclouds.omabar/system/install.sh
```

## Make it yours

Your own layouts go in `~/.config/omarchy/omabar/layouts/`. To change a built-in one, copy it there under the same file name and edit the copy. Per-app rules and settings live in `~/.config/omarchy/omabar/rules.json`.

The easiest way to customise Omabar is to point an AI assistant at **[AGENTS.md](AGENTS.md)**. It documents the layout format, every button type, icons, keys and how the pieces fit together, so the assistant can make changes safely.

Check your setup at any time:
```bash
~/.config/omarchy/plugins/io.github.jonathanintheclouds.omabar/bin/omabar doctor
```

## Uninstall

```bash
sudo ~/.config/omarchy/plugins/io.github.jonathanintheclouds.omabar/system/uninstall.sh
omarchy plugin remove io.github.jonathanintheclouds.omabar
```
Then delete the block between `-- omabar begin` and `-- omabar end` in `~/.config/hypr/bindings.lua`.
